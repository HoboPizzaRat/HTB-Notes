
# Recon
Reconnaisance, it involves the part where the attacker chooses the target and starts enumerating the landscape of the targets structure for any loopholes on the technology. Any openly available info basically.
They look for:
- antivirus tools, operating systems, network technologies.
- scanning systems for further info

# Weaponize
In the `Weaponize` stage, the malware to be used for initial access is developed and embedded into some type of exploit or deliverable payload
- usually very lightweight and undetectable by antivirus and edr
- the sole purpose of this initial stage is to provide remote access to a compromised machine in the target environment

# Delivery
Traditional approaches include phishing emails that either contain a malicious attachment or a link to a web page.
- The web page can serve two purposes: either containing an exploit or hosting the malicious payload to avoid sending it through email scanning tools.

## Exploitation
During the exploitation stage of the Cyber Kill Chain, the attacker typically attempts to execute code on the target system in order to gain access or control.

# Installation
**Droppers**: Attackers may use droppers to deliver malware onto the target system
- email attachments, malicious websites etc
**Backdoors**: A backdoor is a type of malware designed to provide the attacker with ongoing access to the compromised system.
**Rootkits**: A rootkit is a type of malware designed to hide its presence on a compromised system. Rootkits are often used in the installation stage to evade detection by antivirus software and other security tools.
