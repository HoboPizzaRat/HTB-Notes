The Elastic stack, created by Elastic, is an open-source collection of mainly three applications (Elasticsearch, Logstash, and Kibana) that work in harmony to offer users comprehensive search and visualization capabilities for real-time analysis and exploration of log file sources.

The high-level architecture of the Elastic stack can be enhanced in resource-intensive environments with the addition of Kafka, RabbitMQ, and Redis for buffering and resiliency,

The components of elastic search
- **ElasticSearch** is json -based engine design with RESTful api.
	- it handles the indexing, storing and querying security events
- **Logstash** is the one collecting, transforming and transporting log file records.
	- its strength is to consolidate data from various sources 
	- **process input** (logstash ingest records from remote locations, connverting them into format the machines can understand)
		- for example taking data from syslog messages
	- **transform and enriching log records** makes it possible to make more info about events data based on given rules and then it be sent further.
	- **send logs to elasticsearch**
- **Kibana** serves as the visualization tool for elasticsearch documents
	- it enables executing queries through the interface it provides
- **Beats** is additional component. 
	- single purpose data shippers that are installed on remote machines, with a purpose to forward logs and metrics to logstash or elasticsearch directly
