Kibana Query Language (KQL) is a powerful and user-friendly query language designed specifically for searching and analyzing data in Kibana.

As Security Operations Center (SOC) analysts, we are likely to extensively use Kibana as our primary interface when working with the Elastic stack. Therefore, it is essential to become proficient with its functionalities and features.

# The basic query structure

consists of id:value pairs with the field being datas attribute and value being the representing data.
```kibana
even.code:4625
```
- this filters data in Kibana to show events that have the [Windows event code 4625](https://www.ultimatewindowssecurity.com/securitylog/encyclopedia/event.aspx?eventid=4625).


KQL supports free text search, allowing you to search for a specific term across multiple fields without specifying a field name.
```kibana
"svc-sqli"
```


Logical operators allow to group expressions and control the order of evaluation
```kibana
event.code:666 AND winlog.event_data.Substatus:0xC0000072
```

`Comparison Operators`: KQL supports various comparison operators such as `:`, `:>`, `:>=`, `:<`, `:<=`, and `:!`. These allow granular condition matching that matches field values
```kibana
event.code:4625 AND winlog.event_data.SubStatus:0xC0000072 AND @timestamp >= "2023-03-03T00:00:00.000Z" AND @timestamp <= "2023-03-06T23:59:59.999Z"
```


`Wildcards and Regular Expressions` allow regular expression based searches for patterns in field values. For example
```
event.code:4625 AND user.name: admin*
```


## Real world combination of kql in use
```
event.code:4625 AND winlog.event_data.SubStatus:0xC0000072 AND @timestamp >= "2023-03-03T00:00:00.000Z" AND @timestamp <= "2023-03-06T23:59:59.999Z"
```
- searches for failed login attempts
- between march 3rd 2023 and march 6th 2023
